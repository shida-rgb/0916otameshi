# 0916otameshi
お試し用リポジトリ

## 静的サイト（Cursor Projects Test）

ルートの `index.html` がミニマルなテスト用ランディングページです。

### 表示方法

**Python（推奨・追加インストール不要）**

```bash
cd /path/to/0916otameshi
python3 -m http.server 8080
```

ブラウザで [http://localhost:8080](http://localhost:8080) を開いてください。

**ファイルを直接開く**

`index.html` をブラウザにドラッグ＆ドロップ、またはファイルから開くこともできます（CSS は同じフォルダに `styles.css` がある必要があります）。
